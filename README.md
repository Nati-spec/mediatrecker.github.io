# MediaTracker v3.0 — Локальный Full-Stack проект и БД

## Что обновлено в версии 3.0:
1. **Постеры для всех 160 медиаединиц (`seedData.js`):** каждый фильм, сериал и аниме имеет обложку 2:3 + локальный SVG-генератор при отсутствии интернета.
2. **Проверка статуса для рецензий:** оставить отзыв можно только если тайтл находится у пользователя в статусе «Смотрю», «Просмотрено» или «Брошено» (для «В планах» и недобавленных тайтлов форма заблокирована).
3. **Разделенный служебный контур администратора:**
   - У администратора убраны личные списки и оценки — доступны только **Админ-панель** и **Аккаунт**.
   - В каталоге и детальной карточке администратор может **редактировать любые существующие тайтлы** и **добавлять новые**.
   - В **Админ-панели** добавлено создание новых администраторов с **автоматической генерацией одноразового временного пароля**.
   - В **Аккаунте администратора** добавлена функция **передачи аккаунта при увольнении/смене** (генерируется временный пароль, а при входе по нему открывается обязательный экран смены имени пользователя и установки постоянного пароля).
   - **Раскрывающиеся жалобы:** каждая жалоба разворачивается и показывает полный текст комментария, к какому именно тайтлу он относится и причину нарушения.

## Запуск на компьютере:
1. Распакуйте архив в папку без кириллицы (например, `C:\trecer`).
2. Запустите `start_windows.bat` (или в терминале: `npm install`, затем `npm start`).
3. Откройте `http://localhost:3000`.
